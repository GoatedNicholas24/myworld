# VISION (one page)

This is the short version of the long design chat. Read this instead of the full chat. If something here is unclear, ask Nicholas, do not guess.

## Pitch

A living African world where players build their own lives: learn skills, run businesses, make friends, build settlements, explore cultures. The world changes because of what players do.

## Five pillars

1. **Freedom**: no single storyline. Players choose a life.
2. **Mastery**: skills improve by doing the activity, not by buying XP.
3. **Culture**: languages, architecture, music, food and stories shape gameplay.
4. **Economy**: players make, move and sell things to each other.
5. **Consequences**: player actions change towns, prices and the environment.

## Direction chosen

Life simulator in a living world (options A + C from the chat), growing toward a multiplayer open world later.

## The first region

One compact Great Lakes region (Uganda-inspired): a town, a village, a marketplace, a farm, a lake, a workshop, connected roads. First street: Kampala Road (Blender kit already built).

## First five professions and loops

| Profession | Loop |
| ---------- | ---- |
| Farmer | plant, harvest, sell |
| Carpenter | gather wood, craft furniture, sell |
| Trader | buy, carry, sell elsewhere |
| Transporter | carry goods and people |
| Musician | practise, perform at events |

## Rules that must not be broken

- Everything works without paid AI services. AI is an optional extra later.
- Virtual currency only. No real-money earning in early versions.
- Money must have sources AND sinks, or prices break.
- Never sell power. Cosmetics and customisation only. No loot boxes.
- Culture: portray people with dignity. Do not copy sacred or restricted material. Languages and traditions need review by native speakers before they go in.
- No real brand names or logos in shop signs.
- Must run on cheap Android phones and weak laptops.

## Later, NOT now

Multiplayer, player-built cities, local government, radio, player-made content, AI characters, more regions, real-money payouts.
