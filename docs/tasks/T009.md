## Interface (the contract other code relies on)

- `createControls(camera, element, terrain, settings, options)` accepts optional Great Lakes-only landmark, flight and marker callbacks/settings; without options, existing controls remain unchanged.
- The tile terrain exposes `heightAt(x,z)`, `biomeAt(x,z)`, and map source data for the far 251 × 251 height/biome grids.
- `createGreatLakesMapView({ camera, metadata, farHeights, farBiomes })` provides a north-up 180 px minimap, an M-key full map, and an N-key minimap toggle.
- The Great Lakes HUD reports map coordinates, elevation, biome, and river distance as `n/a` until water data is integrated.
