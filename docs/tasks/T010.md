## Interface (the contract other code relies on)

- Tiler writes `tiles/density/density_50m_<resource_id>_u8.bin` (401 × 401, row 0 north, box-average of the 10 m source) and `tiles/density/index.json`.
- `data/vegetation.json` maps each biome ID to ambient vegetation kinds, density per hectare, size ranges, and colours.
- The Great Lakes terrain manager exposes nearby chunk lifecycle hooks for detail systems and a deterministic resource query `resourcesNear(x, z, radius)`.
- Vegetation/resource instances are generated from world seed and chunk coordinates; load order must not affect placement.

## Rules

- Plain JavaScript ES modules, no new dependencies.
- Do not edit `tools/terrain/**`, `tools/blender/**`, `public/terrain/**`, `terrain.json`, or the `moods` block of `worlds/great_lakes/world.json`.

- Use InstancedMesh and reuse geometry/materials; no vegetation on steep slopes, water, or snow/rock peaks.
- At most two chunk builds per frame; LOW/HIGH radii and triangle budgets live in `src/quality.js`.
- Do not edit files outside the list above.
